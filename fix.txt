### 3-1. 中間ファイルのパスをDBで確認（VS Code PostgreSQL拡張機能）
1. VS Codeで st-mid-file-create-process の Dev Container に接続する（左下が「Dev Container: …」になっていること）
2. 左側の PostgreSQL（象のアイコン）を開き、「＋」（新しい接続）をクリック
3. 接続情報を入力して「Connect」
   - SERVER NAME：tes-v2 共通DBのエンドポイント（RDSコンソールの「接続とセキュリティ」で確認）
   - AUTHENTICATION TYPE：Password
   - USER NAME：root
   - PASSWORD：Secrets Manager の rds!db-… の password（画面キャプチャを撮らない）
   - DATABASE NAME：common
4. 接続できたら、common → Schemas → ap1 → Tables に t_zip_unit 等があることを確認
5. 接続を右クリック →「New Query」で、打鍵手順書3-1のSQLを実行する（テーブルは ap1 スキーマ。SQLのテーブル名に ap1. を付けるか、先に set search_path to ap1, public; を実行）
- 参照のみ（select）とし、update／delete等は実行しない。
